# Expensio Dashboard

A React + Vite personal budget tracker with the dark Expensio dashboard treatment applied to the existing project.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL in your browser.

## What changed

- `src/index.css`: Expensio dark dashboard system, responsive layout, panels, charts, forms, and detail styles.
- `src/pages/Dashboard.jsx`: dashboard overview with pending tasks, recent expenses, quick access, report charts, filters, and activity.
- `src/components/Sidebar.jsx`: Expensio navigation rail with inline SVG icons.
